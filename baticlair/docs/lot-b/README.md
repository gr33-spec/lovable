# Lot B : tous les métiers calculent

Chaque paquet a son compte rendu, écrit par son test (il change seulement si le calcul change) :
le devis de test de chaque métier, l'écran à l'ouverture (vert, orange, grise, questions du comptoir),
le PDF lu par le vendeur une fois les questions répondues et chaque « C'est bon » donné, et le tableau de Brest, inchangé.

Orange = une ligne qui attend la réponse à une question du comptoir, ou une quantité calculée avec un ratio « à vérifier » (ou des sources en désaccord) : son chiffre est là, avec « Quantité à confirmer : [règle] ».
« C'est bon » la passe au vert ; trois entreprises différentes qui confirment valident le ratio pour tout le monde.
