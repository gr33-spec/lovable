# Inventaire des ratios couverture (état du 2026-11-19)

Relevé en lecture seule de tous les chiffres du métier couverture présents dans le code, la documentation et le skill du fondateur, pour vérification par sources. Les données sont dans `inventaire-ratios.json` (même contenu, une entrée par objet). Rien n'a été vérifié ici : c'est la liste de ce qu'il faut vérifier.

Sources parcourues : `packages/domain/src/referential/data/roofing.ts` (version `roofing-2026.10.11-51`), `docs/referentiel-couverture.md` (§1-18, 25, 28, 34-36, plus §48.6 et §49.7 cités par le code), `docs/ratios-a-valider.md`, `packages/domain/src/referential/zone.ts`, les tests de `packages/domain/test/`, `.claude/skills/regles-metier/SKILL.md`, `referentiels/couverture/CHANGELOG.md` et `referentiels/metiers/couverture.md` (aucun chiffre).

**369 entrées**, dont **179 avec une contradiction** entre au moins deux origines. Par famille : ardoise 72, tuile 39, tuile_canal 14, tuile_plate 4, faitage_rives 15, noue 6, zinguerie 41, evacuation 17, ecran 6, etancheite 22, bois 11, velux 5, fixation 20, perte 14, conditionnement 15, zone 11, autre 57.

Conventions : `statut_code` reprend la vérification déclarée dans roofing.ts (`FOUNDER_DOC`, `FOUNDER_VALIDATED`, `FOUNDER_CHECKED`, `FOUNDER_REPLY`, `draft`/`todo`) ; « absent du code » = chiffre du document ou du skill qui n'est pas codé. Les entrées « test figé » sont des quantités attendues par les tests, à recalculer si un ratio change.
