## Bilan

- Lignes de données (sections A à E, B.4 et G ; le tableau F, qualitatif, n'est pas compté) : **92**.
- Confirmées par 2 sources : **41** (≈ 45 %) ; 1 source : **29** (surtout le catalogue Siniat 2021/2022, seul document fabricant complet lu en texte intégral) ; à confirmer : **13** ; contradictions documentées : **4** ; règles produit / calcul : 5.
- Ratios cœur du quantitatif, tous confirmés 2 sources : bande 1,40 ml/m² de parement (2,80 pour une cloison) ; enduit poudre 0,33 kg/m² ; enduit pâte 0,47 kg/m² ; bande armée obligatoire sur angle saillant (NF DTU 25.41 § 6.1.4.2.3) ; rail de rive fixé tous les 60 cm ; formats 150 m / 23 m (bande), 30 m (bande armée), 25 kg (sacs), 22 / 17 kg (Placomix Pro).

Contradictions :
1. Bande : Placo 1,40 ml/m² vs Siniat 1,1 ml/m² de plaque (périmètre de comptage probablement différent).
2. MAP Formule + : 1,8 kg/m² (quantitatif Placo 2017, Siniat Prégycolle) vs 2 à 3 kg/m² (fiche Placo MAJ 28/05/25).
3. Placomix Pro : 0,47 kg/m² (Intégrale 2023) vs ≈ 0,525 kg/m² (fiche produit, MAJ 31/03/26).
4. Bande Armée 50 Placo : palette de 200 boîtes vs carton de 10 boîtes (deux EAN différents).

À confirmer (et pourquoi) :
- Rouleau de bande papier de 75 m : absent des gammes Placo, Siniat, Knauf lues.
- Largeur 52 mm : vue seulement chez PSI Groupe ; Placo et Knauf = 50 mm, Siniat = 51 mm.
- Produits Knauf France (Proplak Snow 2h, Proplak Joint, bande, Ultraflex, trappe PLP) : pages knauf.com en 403, seuls des extraits moteur ; aucune consommation Knauf lue.
- « Placo Bande Placotech », « Placocol », « Prégycolle 2000 », « Placoflam mastic », mastic acoustique Placo, « angle souple Placo Stil / Habito » : aucune trace dans les documents lus.
- Bande grillagée autocollante 45 / 90 m : statut DTU non établi (Siniat la dit non conforme pour le joint courant ; Placo ne l'utilise qu'en Hydro).
- Charge par cheville Molly sur BA13 standard (15 à 30 kg) et seuil « renfort au-delà de 30 kg » : sources grand public ou forum seulement.
- Pertes ajoutées sur bande et enduit (0 % proposé) ; marge 5 % sur cornière de rive et bande résiliente.
- Nombre de sacs de 25 kg par palette Placo (PR4) ; durée de prise PR1 / PR8 ; Perlfix en France.
- Profil de joint de dilatation, renforts de charges lourdes (traverses, platines), mousse expansive coupe-feu, boîtiers Schneider / Hager : non trouvés ou non recherchés.
- Catalogue Siniat 2021/2022 : dernière édition PDF trouvée ; une édition plus récente peut exister (Siniat, groupe Etex).
